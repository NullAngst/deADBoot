# deADBoot common bloat list.
#
# "Mark common bloat" in Apps, Debloat ticks every loaded package that matches this list.
# It never removes or disables anything by itself: you review the ticks, untick what you use,
# tick anything else you want gone, then press Disable or Remove yourself.
#
# Format:
#   ## Group name          the group shown in the Note column for the lines under it
#   com.example.app        one exact package name
#   com.example.*          every package starting with "com.example."
#
# The do-not-touch list (debloat-protected.txt) always wins over this one.
# Add your own entries in ~/.local/share/deadboot/debloat-common.txt
# (Windows: %LOCALAPPDATA%\deADBoot\debloat-common.txt). They are merged with these.
